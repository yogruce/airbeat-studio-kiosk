# AirBeat Studio — Kiosk Edition

Kamera karşısında el ve parmak hareketlerinizle gerçek zamanlı olarak **7 farklı enstrüman** çalmanızı sağlayan, **Kiosk holografik kutu/ped arayüzlü** ve düşük gecikmeli masaüstü müzik stüdyosu.

## Enstrümanlar
1. **Bateri (`[1]`)**: 5 parçalı holografik davul pedi + `[SPACE]` Kick pedalı
2. **Gitar (`[2]`)**: Sol Kiosk akor/perde kutuları + sağ yatay tel vuruş alanı + Sustain
3. **Piyano (`[3]`)**: 12 geniş neon tuş + 10 parmak polifonik basım + Sustain
4. **Keman (`[4]`)**: Sol dikey nota skalası + sağ el yay kontrolü + kesintisiz Sustain
5. **Çello (`[5]`)**: Derin bas yaylı çello skalası + kesintisiz Sustain
6. **Saksafon (`[6]`)**: 6 perde parmak tuşu + nefes/enerji kontrolü
7. **Orkestra Şefi / Maestro (`[7]`)**: Sağ el baton temposu + sol el dinamik crescendo kontrolü

## Kısayol Tuşları
- **`[1]` - `[7]`**: Enstrüman seçimi (veya üstteki kapsüllere el/fare ile dokunma)
- **`[M]`**: Çalma Modu Değiştir (`SOLO NOTA` ↔ `AKOR` ↔ `HİBRİT`)
- **`[G]`**: Gam Kilidi (Scale Quantization) Değiştir
- **`[S]`**: Ayarlar Ekranı (Kamera, Ses Çıkışı, Görsel Mod, Hassasiyet)
- **`[V]`**: Görsel / Performans Modu Değiştir
- **`[L]` / `[C]`**: 4-Bar Live Looper Kayıt Aç-Kapat / Temizle
- **`[F]`**: Tam Ekran (Fullscreen)
- **`[ESC]`**: Çıkış

## Kurulum ve Çalıştırma

```bash
pip install -r requirements.txt
python main.py
```
